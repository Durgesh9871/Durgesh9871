## 🧠 AI system workflow

The system pattern I am building is an explicit, inspectable graph:

~~~mermaid
flowchart LR
    A[Question] --> B[Intent + auth]
    B --> C[Retrieve context]
    C --> D[Plan + tools]
    D --> E[Validate output]
    E --> F[Execute safely]
    F --> G[Evidence answer]
    G --> H[Evaluate + observe]
~~~
